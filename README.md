As part of this challenge, I extracted data from large data sets using Numpy, Pandas and other relevant Python modules (e.g. Rasterio) and manipulated it (i.e. cleaning, transformation, filtering  etc.) to create a random forest regression model that predicts urban heating. The features used were spectral data (e.g. showing vegetation levels) from Sentinel-2 satellite data, building concentration from building footprint data and canopy height from elevation models. Accuracy score was 96%. The main workbook in which data is gathered and for which a model is created is "v3_UHI Experiment.ipynb".
